# Project Constitution

## Vision
AI-powered civic grievance management system for Telangana to auto-classify and route citizen complaints to correct departments.

## Core Principles
1. **Citizen First**: Easy complaint submission, instant tracking ID
2. **AI Accuracy**: >90% classification accuracy for Road, Water, Electricity, Garbage, Street Lights
3. **Transparency**: Real-time status updates via portal/SMS
4. **Data Privacy**: No personal data shared without consent

## Technical Constitution
- **Backend**: Python 3.10+, FastAPI, SQLAlchemy
- **Frontend**: React 18, Vite, TailwindCSS
- **AI/ML**: Gemini/LLM for complaint classification
- **Database**: SQLite for dev, PostgreSQL for prod
